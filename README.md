# netflix-data-analysis
Exploratory data analysis of a streaming platform dataset using R

## Overview
This project explores a streaming platform dataset to identify patterns in content distribution, production trends, and catalog characteristics.

## Tools Used
- R
- tidyverse
- ggplot2
- R Markdown

## Key Insights
- The catalog is dominated by movies over TV shows
- The United States and India are the main content producers
- TV shows show sustained growth compared to movies
