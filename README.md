# netflix-data-analysis
Exploratory data analysis of a Netflix titles dataset using R.

## Overview
This project explores a Netflix titles dataset to examine catalog composition, title distribution across release years, country associations, and content ratings.

Using data cleaning, exploratory data analysis, and visualization techniques, the project compares movies and TV shows and summarizes patterns in the available historical data.

## Tools Used
- R
- tidyverse
- ggplot2
- R Markdown

## Key Insights
- Movies represent a larger share of the catalog than TV shows.
- The United States has the highest number of title-country associations, followed by India and the United Kingdom.
- Title counts vary across release years, with high counts among titles released in the late 2010s.
- Content ratings vary in frequency across the catalog.
